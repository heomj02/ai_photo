실기기는 제조사·Android 버전·해상도·권한 상태와 성공/실패를 기록한다.
에뮬레이터는 탐색·권한 흐름 확인에 쓰며 실제 후면 카메라 검증을 대신하지 않는다.

## AI MVP 후속

한 사람과 Reference 한 장으로 시작한다. 중심 인물을 화면 오른쪽에 두었을 때
촬영자 움직임과 모델 움직임에 맞는 서로 다른 좌우 안내인지 확인한다.
인물 높이가 목표 0.65, 현재 0.82이면 뒤로 이동 안내로 비율이 줄어드는지 확인한다.
왼팔이 낮으면 raiseLeftArm인지 확인하고 mirror/rotation에도 동일 의미인지 검증한다.
위치·크기 변화만으로 pose 점수가 크게 달라지지 않는지, 가려진 관절/여러 명/미검출을
잘못된 높은 점수로 처리하지 않는지 검사한다.
readiness 경계값과 유지시간 전후, 흔들림, 중간 미검출, 촬영 중 재진입을 테스트한다.

Debug Overlay는 preview FPS, inference FPS/latency, bbox/keypoints,
composition/pose/readiness, pitch/roll, current instruction을 제공하고 release에서는 숨긴다.
저성능 기기에서 추론 프레임 누적, 화면 멈춤, 발열, 배터리, 메모리를 기록한다.

## 장기 품질 검증

기본 카메라와 AI Photographer로 같은 Reference를 따라 찍어 비교한다.
약 20명 사용자에게 촬영 난이도, 유사도, 지시 이해도/빈도, 자동촬영 자연스러움을 묻는다.
Solo는 이어폰 연결/해제와 화면 없는 촬영, Model Phone은 지연/재연결/결과 공유/재촬영,
Selfie는 좌우 반전과 눈/시선, Group은 전체 인원 준비 상태를 검증한다.
배경 추천은 이미지 유사도뿐 아니라 실제 공간 재현 가능성과 미적 결과로 평가한다.
촬영 전 초점/노출과 촬영 후 색감 보정의 효과를 따로 비교한다.
